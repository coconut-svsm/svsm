Enums§

InodeNamespace
The 64-bit CocoonFS inode number is split into two halves: the upper 32 bits are statically assigned to each service here, and the lower 32 bits are managed by the service itself. Namespace 0 is reserved: although CocoonFS currently only reserves the first 16 inodes for internal use, all inodes with the upper 32 bits set to zero are kept reserved for simplicity.
