EarlyLogBuffer 🔒
A fixed size buffer holding the log messages emitted before the file system is up and the regular log buffer can be used. It needs no heap and no per-CPU state, so it is usable from the very beginning of kernel startup. switch_to_log_buffer() copies its contents to the regular log buffer, after which it is never used again.

Constants§

EARLY_LOG_PREFIX 🔒
Prefix added to messages stored in the early log buffer. It matches the prefix the idle task uses once the regular log buffer has taken over, so that the log reads continuously across the hand-over.
EARLY_LOG_SIZE 🔒
Size of the early log buffer. One page is plenty: only a handful of messages are emitted before the regular log buffer takes over.
EARLY_LOG_TRUNCATED 🔒
Appended to the early log buffer contents when messages were dropped because the buffer ran out of space.
